GarageDrop

Le jeu de collection de voitures : tape, ouvre des boîtes, garde ou revends, et complète ton carnet de 1 185 versions.

Assistance

Une question ou un problème ? Ouvre une demande sur la page du projet.

Astuce : pour changer de téléphone sans perdre ta partie, ouvre ton compte (en haut à gauche), exporte ton code de sauvegarde, puis restaure-le sur le nouvel appareil.

Confidentialité

GarageDrop ne collecte aucune donnée personnelle. Lire la politique de confidentialité.
